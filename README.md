# Farhad Al-Amin Dipto — academic homepage

Static personal page: research interests, publications and preprints, ongoing work,
selected projects, education and awards.

Live: https://legend-2727.github.io/Farhad-Al-Amin/

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The whole page (no build step, no JavaScript) |
| `styles.css` | Styles, including dark mode and print |
| `photo.jpg` | Portrait |
| `CV.pdf` | Current CV |

## Local preview

```bash
python -m http.server 3000
```

Then open http://localhost:3000.

## Deployment

Served by GitHub Pages from `main`. `netlify.toml` is kept for the Netlify mirror.
